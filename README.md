# Roots & Routes Foundation - Coming Soon Landing Page

একটি আধুনিক, মিনিমালিস্টিক এবং মার্জিত কামিং সুন (Coming Soon) ল্যান্ডিং পেজ—যা একটি মানবিক ও সহায়তামূলক ফাউন্ডেশনের গাম্ভীর্য ও পেশাদারিত্ব ফুটিয়ে তোলার জন্য বিশেষভাবে ডিজাইন করা হয়েছে।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **ফাউন্ডেশন ব্র্যান্ডিং ও দ্বৈত লোগো (Dual Logo Variants):**
   - **Mark Icon:** ক্রিস্টাল ক্লিয়ার ও ফ্লুইড 'r' সিম্বলসহ রোজ-ক্রিমসন স্কয়ার আইকন।
   - **Full Brand Logo:** আইকন এবং পরিশীলিত সেরিফ টাইপোগ্রাফিতে *Roots & Routes Foundation*।
   - ক্লিক করে সরাসরি লোগো ভিউ টগল করার সুবিধা।

2. **লাইভ টাইম কাউন্টডাউন (Live Digital Countdown):**
   - দিন, ঘণ্টা, মিনিট ও সেকেন্ড কার্ড সম্বলিত ফ্লুইড গ্লাস ডিসপ্লে (রেফারেন্স ডিজাইনের আদলে)।
   - অ্যাডমিন প্যানেল থেকে যেকোনো সময় উদ্বোধনের তারিখ পরিবর্তনযোগ্য।

3. **সহজ ইমেইল সাবস্ক্রিপশন (Email Subscription & Alerts):**
   - ভ্যালিডেশন ও ডুপ্লিকেট চেকিং সুবিধাসহ সাবস্ক্রিপশন বার।
   - কনফেটি অ্যানিমেশন ও তাৎক্ষণিক ফিডব্যাক।

4. **পূর্ণাঙ্গ ডোনেশন পোর্টাল (Humanitarian Donation Portal):**
   - bKash, Nagad, Rocket, Bank Transfer এবং Card সাপোর্ট।
   - ১-ক্লিক নম্বর কপি করার অপশন।
   - খাতের বিবরণ (পথশিশুদের শিক্ষা, খাদ্য ও পুষ্টি, চিকিৎসা সহায়তা ইত্যাদি)।
   - Transaction ID জমা দিয়ে ভেরিফিকেশনের ব্যবস্থা।

5. **ডার্ক ও লাইট মোড (Dark & Light Mode):**
   - এক ক্লিকে ডার্ক এবং লাইট মোডের মধ্যে পরিবর্তন।

6. **দ্বিভাষিক সাপোর্ট (Bangla & English):**
   - বাংলা এবং ইংরেজি উভয় ভাষায় পুরো সাইট ব্যবহারের সুবিধা।

7. **সহজ অ্যাডমিন কন্ট্রোল প্যানেল (Easy Admin Portal):**
   - স্ক্রিনের নিচের ডান কোণে গোপন লক আইকনে ক্লিক করে অথবা পিন দিয়ে প্রবেশ করুন।
   - **ডিফল্ট অ্যাডমিন পিন:** `admin123`
   - সাবস্ক্রাইবার তালিকা দেখা, সার্চ করা এবং ১-ক্লিকে **CSV এক্সপোর্ট** করা।
   - সংগৃহীত ডোনেশন রেকর্ড ও ট্রানজেকশন ভেরিফাই/পেন্ডিং পরিবর্তন করা।
   - কাউন্টডাউন ডেট, ফোন নম্বর, ঠিকানা এবং সোশ্যাল মিডিয়া লিংক লাইভ পরিবর্তন করা।

8. **ডাটাবেজ ও ফায়ারবেস সাপোর্ট (Firebase Firestore & Local Persistence):**
   - ফায়ারবেস ক্রেডেনশিয়াল যুক্ত থাকলে সরাসরি রিয়েলটাইম ফায়ারবেসে ডেটা সেভ হয়।
   - ফায়ারবেস ছাড়াও কোনো ত্রুটি ছাড়া লোকাল ব্রাউজারে স্বয়ংক্রিয়ভাবে চলে।

## 🚀 গিটহাব ও ভার্সেলে ডেপ্লয় করার নিয়ম (GitHub & Vercel Deployment)

এই প্রজেক্টটি **Vercel**-এর জন্য সম্পূর্ণ কনফিগার করা আছে (`vercel.json` ফাইলে)।

### ধাপ ১: গিটহাবে কোড পুশ করুন
```bash
git init
git add .
git commit -m "feat: Roots & Routes Coming Soon landing page"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/roots-routes-coming-soon.git
git push -u origin main
```

### ধাপ ২: Vercel-এ হোস্ট করুন
1. [vercel.com](https://vercel.com)-এ যান এবং আপনার GitHub দিয়ে লগইন করুন।
2. **"Add New" > "Project"** সিলেক্ট করুন।
3. আপনার গিটহাব রিপোজিটরিটি নির্বাচন করে **"Deploy"** বাটনে চাপুন।
4. ব্যস! ১ মিনিটের মধ্যে আপনার সাইট লাইভ হয়ে যাবে।

## ⚡ ফায়ারবেস সংযোগ (Firebase Setup - Optional)

আপনি যদি Vercel বা লাইভ সাইটে রিয়েলটাইম ফায়ারবেস ক্লাউড ডাটাবেজ ব্যবহার করতে চান:
1. [Firebase Console](https://console.firebase.google.com)-এ গিয়ে একটি নতুন প্রোজেক্ট খুলুন।
2. **Firestore Database** চালু করুন।
3. **Project Settings** থেকে Web App তৈরি করে কনফিগ ভ্যালুগুলো সংগ্রহ করুন।
4. Vercel ড্যাশবোর্ডের **Settings > Environment Variables**-এ নিচের ভেরিয়েবলগুলো যুক্ত করুন:
   ```env
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
   VITE_FIREBASE_APP_ID=your_app_id
   ```
5. সিকিউরিটি রুলসের জন্য প্রজেক্টের `firestore.rules` ফাইলটি ফায়ারবেস কনসোলে পেস্ট করুন।
